# Computer Graphics and VR Labs

A collection of lab programs covering core computer graphics algorithms, rendering, and interactive 3D scenes.

## Labs

1. **DDA and Bresenham line drawing** - raster line generation.
2. **Midpoint circle drawing** - circle generation using symmetry.
3. **2D transformations** - translation, rotation, scaling, reflection, and shearing.
4. **Composite transformations** - combining transformations with matrices.
5. **Cohen-Sutherland clipping** - clipping lines to a viewing window.
6. **Z-buffering** - hidden-surface removal.
7. **Phong illumination** - lighting a 3D object.
8. **OpenGL shaders** - vertex and fragment shader rendering.
9. **Interactive Unity scene** - interacting with 3D objects.
10. **3D viewing pipeline** - projection and viewport mapping.

Programs are implemented across Python, OpenGL/GLSL, and Unity C#; see each lab folder for source files and output images.
